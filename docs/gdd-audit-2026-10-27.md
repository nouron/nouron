# GDD-Audit 2026-10-27 — Abgleich mit dem Code

**Anlass:** Owner-Hinweis, das GDD sei veraltet (Supply → Kolonisten, zweiter Harvester gestrichen, keine Flotten, keine Trennung Kolonie/User-Ressourcen, kein Mehrspieler).
**Methode:** `docs/GDD.md` (komplett, 3091 Zeilen) und die Unterkapitel in `docs/gdd/` gegen `config/*.php`, `database/seeders/data/`, Services/Controller, `GLOSSAR.md`, ROADMAP und CHANGELOG geprüft. Code gilt als Wahrheit; wo eine Owner-Entscheidung im GDD dem Code widerspricht, ist das unter B ausgewiesen und nicht stillschweigend entschieden. Tests wurden nicht ausgeführt, Code wurde nicht geändert.
**Ergebnis:** Teil A ist im GDD korrigiert (zahlenfrei, ohne Historie, ADR 0004). Teil B sind Code-Reste und Abweichungen für die ROADMAP (T43-H6 ff.). Teil C sind Fragen an den Owner.
