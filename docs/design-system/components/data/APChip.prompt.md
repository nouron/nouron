Used on the canvas header/legend to show remaining AP pools by category — distinct from `Button`'s inline AP-cost chip, which shows a fixed price rather than a pool total.

```jsx
<APChip type="build">3 Con AP</APChip>
<APChip type="nav">0 Nav AP</APChip>
```

Colors: nav=blue, build=green, research=violet, economy=amber, strategy=rose, neutral=gray.
